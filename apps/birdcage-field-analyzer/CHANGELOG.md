- 축 범위 수동 보정과 8개 leg 색상 선택/스포이트 기능 추가
- mA/µA/nA/A 단위와 leg별 +z/−z current-reference 정규화 추가
- 색상 중복 방지, 연속 경로 추적, legend 선분 제거와 주기 적합 보간 추가
- 시간–전류 곡선 디지타이징과 검출률/R² 표시 추가
- Leg 1 +X, 반시계 45° 간격의 8-leg 상면 배치 추가
- 유한 직선도체 Biot–Savart 자기장과 leg별/합성 벡터 표시 추가
- 공간 자기장 벡터, 편파 궤적, Bx/By, 위상차, axial ratio 계산 추가
- 시간 슬라이더, 연속 재생, 속도 조절 및 CSV 내보내기 추가
- 원형편파와 X축 강조 합성 검증 데이터 추가
