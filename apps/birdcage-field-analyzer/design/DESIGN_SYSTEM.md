# Birdcage Field Analyzer 디자인 시스템

`concept.png`에서 추출해 실제 정적 GUI에 적용한 화면 규칙이다.

## 화면 구조

- 상단: 짙은 navy 도구막대, 제품명, 데이터 상태, 이미지 불러오기
- 좌측: 입력 이미지 → 축 보정 → 8개 trace 설정의 순차 작업 rail
- 중앙: 8-leg 상면 배치와 leg별/합성 자기장 벡터
- 우측: Bx/By, 편파 궤적, 순간장, 기하 조건
- 하단: 8개 전류 파형과 시간 slider/playback

## 시각 토큰

- 배경: `#eef3f7`
- 카드: `#ffffff`
- 헤더: `#0b2e4f` 계열
- 주 동작: `#2563eb`
- 본문: `#102a43`
- 보조 본문: `#60748a`
- 경계: `#d7e0e9`
- 성공/균형: `#10b981`
- X축 우세/경고: `#ef4444`
- Y축 우세: `#f97316`
- 글꼴: `Malgun Gothic`, Arial, sans-serif

## 정보 표현

- 8개 leg 색은 ANSYS 기본 trace 색과 맞춘다.
- 합성 자기장은 굵은 navy 화살표, leg별 기여는 각 trace 색의 반투명 화살표다.
- +z 전류는 점, −z 전류는 십자 기호로 나타낸다.
- 비율·편파 수치는 우측 rail에서 그래프와 나란히 읽히도록 배치한다.
- mobile에서는 rail을 세로 적층하고 time slider를 독립 행으로 내린다.

## 상호작용

- 주요 동작은 파란색 실선 버튼, 보조 동작은 흰색 윤곽 버튼이다.
- 이미지 plot 영역은 파란 점선 사각형, 수동 지정 중에는 주황 점선으로 표시한다.
- 모든 canvas는 `ResizeObserver`로 컨테이너 크기에 맞춰 다시 그린다.
- 애니메이션 감소 OS 설정을 존중한다.
