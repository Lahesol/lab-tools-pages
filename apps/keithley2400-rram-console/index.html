통신 성공은 DUT 안전이나 출력 차단을 증명하지 않습니다.

  • 12400 후면 RS-232 DB-9 ↔ USB-serial 어댑터가 straight-through 케이블인지 확인 (null-modem 금지)
  • 2TXD/RXD/GND, 케이블·프로브·절연 상태를 출력 OFF에서 점검
  • 32400 COMMUNICATION 메뉴의 baud, 7/8 bit, parity, terminator, XON/XOFF와 일치 확인
  • 4프로브 스테이션의 수동 접촉, DUT ID, 극성·공통단·허용 전압/전류를 별도로 확인
  • 5OUTPUT 표시가 꺼져 있는지 장비 전면에서 확인한 뒤에만 포트 연결
