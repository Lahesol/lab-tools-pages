PT3-capable controller firmware is checked after connection.

VBIAS0/CE0 uses the 6-bit DAC in PT3; VZERO0/gate uses the 12-bit DAC. These are DAC-code-derived setpoints, not ADC voltage measurements. SINC controls change the time-domain noise/bandwidth trade-off; all DSP settings are stored as CSV metadata. DFT is intentionally not used here because it would replace the pulse trace needed to fit τ. PT3 supports static step settings, not a continuous DAC waveform. HSTIA RTIA is calibrated at 10 kΩ with PGA ×9 before every RUN; source reference remains fixed at 1.100 V. VZERO0 is intended for a high-impedance gate/base; a 200 kΩ load attenuated its DC step to about 15% in the fixture validation.

Hardware gate

PT3에서는 VZERO0를 DUT gate/base 전용 fixture contact로 직접 연결하고 PAD4/RE0는 개방합니다. RUN 명령 전 ADIID와 HSTIA RTIA 교정을 확인합니다. AFE_ID, AFE_SPI, 또는 PT3_CAL 오류가 오면 측정과 DUT DAC setpoint 적용은 시작되지 않으며 BLE/DFU는 유지됩니다.
