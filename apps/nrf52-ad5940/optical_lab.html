3. Light stimulus

A run applies the selected channel set after the dark baseline, retains it for the pulse duration, then sends OFF,ALL and records post-pulse relaxation.

Outputs are disabled by default.

Timing boundary

PT3 uses its indexed AD5940 sample clock. LED edges are commanded through a separate BLE link, so the recorded event time is a host/BLE marker—not a hardware trigger timestamp.

For an absolute optical edge reference, route a LED-board timing GPIO to an AD5940/nRF GPIO or record it on an oscilloscope.
