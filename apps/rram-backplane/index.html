단일 DAC Pulse · MUX 연결 유지

선택 DUT / 위의 CC+·CC− 사용. 전압: ±20 mV 이상, +3 V/−1 V까지. S16 영점 확인 → 필요 시 방향 전환·재확인 → SAFE에서 DUT 연결 → DAC 목표 전압 → DAC SAFE 복귀 → DUT 연결 유지 100 ms·ADC 8회 검사 → S16(CC·방향 유지). v89 필요, 최소 50 µs. 정상 펄스 시작·끝에서 MUX 주소/EN을 바꾸지 않습니다. 보호 오류는 즉시 격리하며 CPU 지연에는 복귀 예정 시각+250 ms 하드웨어 차단이 있습니다. CC에 의해 실제 전압이 제한될 수 있고 아날로그 pulse 폭·피크는 미검증입니다. 짧은 pulse에는 내부 ADC 표본이 없으며 READ 저항을 자동 추정하지 않습니다.
