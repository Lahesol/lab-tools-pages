STM/LTM IF and O/E/O coupling guide

STM integrate-fire

STM is treated as a transient current source. The TIA voltage charges a leaky IF state; when the state crosses the IF threshold, the local emitter sends a short UV pulse, then the IF state resets and enters refractory time.

  1. UV input creates I_photo(t) in the source device.
  2. TIA converts current to V_TIA(t).
  3. Driver output charges x_IF(t).
  4. If x_IF >= theta_IF, emit a UV pulse to connected targets.

LTM latch/readout

In hybrid mode, LTM does not spike by default. Sustained or repeated input writes a latch state. That state decays slowly and drives persistent optical readout, so the downstream target receives a longer UV contribution than the STM case.

  1. V_TIA(t) is compared with the LTM write threshold.
  2. If the threshold is exceeded, s_LTM(t) is written or reinforced.
  3. s_LTM(t) decays with retention tau.
  4. Readout gain converts the latch state to emitted UV.

LTM through IF mode

If transfer mode is set to integrate-fire for all sources, LTM current also drives the IF block. Because LTM current relaxes more slowly, the IF state can cross threshold after delayed accumulation or fire repeated pulses under sustained retention.

  1. LTM extends the current tail after UV turns off.
  2. The longer tail keeps charging x_IF(t).
  3. Threshold crossing can happen later than STM.
  4. The emitted UV still fans out through the same O/E/O edge model.
V_TIA(t) = |I_photo(t)| * R_TIA
u_driver(t) = clip((V_TIA(t) - V_threshold) * G_driver, 0, UV_max)
STM IF: dx_IF/dt = (u_driver - x_IF) / tau_IF; if x_IF >= theta_IF -> emit UV pulse, reset, refractory
LTM latch: ds_LTM/dt = -s_LTM / tau_retention; if u_driver >= theta_write -> reinforce s_LTM; UV_out = readout_gain * s_LTM
Edge UV: UV_target(t) = UV_external residual + delayed emitted UV * coupling * splitter factor

Simulator Glossary

Definitions used across UV input, device modeling, block connection, O/E/O, ANN, SNN, and dataset mapping panels.

Frequency

UV PWM repetition rate. It controls how often optical pulses are applied to the device model.

Duty cycle

Fraction of each PWM period where UV is on. Higher duty generally increases integrated optical dose.

UV intensity

Normalized optical input amplitude. It is unitless in the browser compact model until calibrated to measured irradiance.

Device block

One optical STM/LTM synaptic device. Its input is UV drive and its output is photocurrent.

STM

Short-term memory mode with fast transient decay. In the O/E/O hybrid model it drives an integrate-fire emitter.

LTM

Long-term memory mode with slower retention. In the O/E/O hybrid model it behaves as a latch/readout state.

Adaptive threshold neuron

Hardware primitive where STM current produces the fast membrane-like signal and LTM state shifts the comparator threshold after firing.

Threshold adaptation

Repeated spikes write LTM state that raises Vth, reducing later firing under the same UV pulse train.

Threshold sensitization

LTM state lowers Vth so previous firing history makes later weak inputs easier to detect.

Switching route

Bias method used to select STM/LTM behavior: VDS route or gate route.

VDS route

Gate fixed at 0 V while VDS is changed between -30 V and +30 V.

Gate route

VDS fixed at +30 V while gate voltage is changed between 10 V and 40 V.

Photocurrent gain

Compact-model current response scale for normalized UV input.

Dark current

Baseline current when UV input is off.

Rise tau

Time constant for current rise under UV illumination.

Decay tau

Time constant for current decay after UV input turns off.

Retention

Residual current or state that remains after optical input. It represents memory persistence.

RMSE

Root-mean-square error between measured transient data and simulated model trace.

TIA

Transimpedance amplifier. It converts photocurrent to voltage: |V_TIA| = I_photo x R_TIA.

O/E/O path

Optical-electrical-optical transfer: UV input produces device current, TIA/driver electronics create a state, and an emitter sends UV to connected target devices.

STM IF event

In hybrid mode, STM current is converted to TIA voltage and accumulated by a leaky IF state. A UV pulse is emitted only after threshold crossing, followed by reset and refractory time.

LTM latch event

In hybrid mode, LTM is modeled as write-and-readout memory rather than a spike generator. Input above write threshold reinforces a slow latch state that drives persistent emitted UV.

LTM routed through IF

When integrate-fire is forced for all sources, LTM also drives the IF block. Its retained current can produce delayed threshold crossing or repeated emission under sustained input.

Driver threshold

Minimum |V_TIA| required before the emitter produces UV output. Higher threshold suppresses weak STM transients.

Driver gain

Slope from |V_TIA| above threshold to emitted UV intensity. Higher gain makes small voltage changes produce larger optical output.

Max emitted UV

Saturation limit of the local emitter output. This caps UV_out before splitter and coupling losses.

Splitter loss

Optical power loss applied when one source drives fan-out connections. Larger dB loss reduces delivered edge UV.

Optical coupling

Efficiency factor from emitter/output guide to target device input. It scales delivered edge UV.

Direct UV residual

Fraction of external UV that still reaches a connected target even without source-emitted UV.

Delay

Propagation or driver delay applied to emitted UV before it becomes target optical input.

IF tau

Leaky integration time constant for STM integrate-fire emitter state. Longer tau accumulates repeated pulses more strongly.

IF threshold

Integrator state level required to fire an emitter pulse. Lower threshold produces more UV output events.

IF gain

Input scaling from continuous driver output into the STM integrator. Higher gain charges the integrator faster.

Emitter pulse

Duration of UV pulse emitted after integrate-fire threshold crossing.

Refractory

Minimum interval after firing before the STM integrate-fire emitter can fire again.

Write threshold

LTM latch input threshold. Above this, the LTM output state is written or reinforced.

Readout gain

Scale factor from LTM latch state to persistent optical/readout output.

Retention tau

Decay time constant of the LTM latch/readout state in the compact O/E/O model.

Dataset target

Dataset selected for architecture mapping. The GUI checks whether dataset input/output dimensions match placed devices.

Input encoding

Method for converting dataset samples into UV pulse sequences, amplitudes, rates, or latencies.

Virtual adapter

Assumed encoder/readout layer used when physical device count does not match dataset channels or class count.

ANN activation

Normalized analog response used as a browser-side readout proxy. It is not trained-model accuracy.

LIF neuron

Leaky integrate-and-fire neuron model used in the SNN tab.

I_syn

Synaptic current derived from device photocurrent and used to drive LIF membrane state.

Spike raster

Time-vs-device plot showing when simulated output spikes occur.

TTFS

Time-to-first-spike encoding. Stronger input is represented by earlier spike timing.

Proxy score

Weighted browser-side optimizer score from compact simulation metrics. It is a screening metric, not measured model accuracy.

Separation objective

Optimizer objective that rewards output margin, dynamic range, or class/event distinguishability.

Sparsity objective

Optimizer objective that rewards useful but not excessive SNN/IF events.

Energy proxy

Optimizer penalty based on optical output, delivered edge UV, and current activity in the compact model.

Robustness objective

Optimizer objective that penalizes saturation, disconnected graphs, and dataset-device adapter requirements.
