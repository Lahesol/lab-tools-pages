Initial UART DFU setup

Loading

Install the DFU-capable initial firmware once with a hardware programmer. After this step, future firmware updates can be done from each project's web GUI through Web Serial.

Setup flow

  1. Flash the initial DFU-capable image once using a hardware programmer.
  2. Open the project web GUI over HTTPS or localhost.
  3. Connect to the board application UART from Chrome or Edge.
  4. Use the project DFU tab to enter bootloader mode.
  5. Run browser UART DFU with the bundled latest ZIP package.
  6. Reconnect and verify the firmware version with VER?.

Raw HEX files are for first-time programmer setup. Browser DFU uses a signed Nordic DFU ZIP after a compatible bootloader is already installed.

How To Add

Add a new entry to apps.json. Keep each app running on its own local port, then link it here or proxy it under one HTTPS domain later.
